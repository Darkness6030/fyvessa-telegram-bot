# Аудит требований

Актуализировано 20.08.2026 по `specifications.xmind`, `finances.xmind`, `fixes.txt` и фактическому коду. Прямые уточнения имеют приоритет: email и web-админка исключены, отзывы вынесены во внешний канал, категории определяются названиями товарных листов Google Sheets.

Статусы: **готово**, **частично**, **не сделано**.

## Пользовательская часть

| Блок | Статус | Фактическое состояние |
|---|---|---|
| Бот и приветствие | Готово | Обычный первый `/start` показывает отдельное приветствие только с кнопкой «СТАРТ». При реферальном первом запуске бот сразу показывает ссылки площадок и переход к подтверждению; при последующих `/start` стартовое сообщение показывается сразу. Кнопка каталога открывает Mini App, рядом доступны канал, отзывы и поддержка. |
| Mini App и авторизация | Готово | FastAPI/Jinja2 интерфейс, подписанный Telegram `initData`, без cookie-сессий. |
| Каталог и категории | Готово | Поиск и фильтры; «Популярное» находится только на главной с рекламой, «Новинки» также выводятся по категориям. Оба признака задаются только чекбоксами Sheets; категория равна названию товарного листа. |
| Товар и фото | Готово | Данные и цены синхронизируются из листа категории. Встроенные изображения извлекаются в максимальном качестве, доступном в экспорте Sheets; отсутствующее фото заменяет placeholder. |
| Карточка товара | Готово по текущему scope | Фото, описание при наличии, публичные характеристики, цены, избранное, корзина и запрос наличия. Встроенные отзывы исключены из продукта. |
| Избранное и недавние | Готово | Добавление/удаление избранного и ограниченная история просмотров. |
| Корзина и наличие | Готово | Изменение количества, запрос администратору, автообновление статуса и блокировка checkout без подтверждения. Подтверждение автоматически перестаёт действовать через час, в том числе в уже открытой корзине. |
| Профиль и регистрация | Готово для заказа | Имя, фамилия, дата рождения и телефон; email отсутствует. Заказы, баланс и скидка отображаются. |
| Скидки, промокоды и коины | Готово | Взаимоисключающий выбор персональной скидки/промокода, затем коины; журнал и возврат при отмене. |
| Рефералы | Готово с ограничением внешних API | Есть персональная ссылка, фиксация пригласившего, ссылки площадок и переход к подтверждению в реферальном старте бота, отдельные настраиваемые награды пригласившему и подписавшемуся, снимки сумм, защита от повторов и однократное повышение скидки. Telegram проверяется автоматически; Instagram/TikTok/YouTube требуют ручного подтверждения до получения отдельных API/OAuth-доступов. |
| Оформление и оплата | Готово | Имя, фамилия, телефон, СДЭК/Почта России/Ozon и адрес пункта выдачи; затем ручной перевод и подтверждение администратором. |
| Темы и анимация | Готово | Светлая/тёмная тема сохраняется и плавно применяется целиком; рекламные карточки переключаются автоматически и свайпом, товары прокручиваются только вручную. |
| История доставки | Готово | В истории заказа сохраняются получатель и доставка; отображаются статусы «Оформлен», «Собирается», «Отправлен», «Доставлен». |
| Поддержка | Частично | Есть внешняя Telegram-ссылка; встроенных обращений и истории нет. |
| Отзывы | Готово по уточнению | Только внешний Telegram-канал из `Настройки`; моделей и модерации отзывов нет. |

## Администрирование и финансы

| Блок | Статус | Фактическое состояние |
|---|---|---|
| Admin flow | Готово для операций | Пользователи, скидки, наличие, заказы, промокоды, выплаты, баннеры, соцсети, реферальные проверки, коины, сводка и синхронизация доступны в `ADMIN_CHAT_ID`. |
| Финансовый снимок | Готово | При первой подтверждённой оплате фиксируются цены, скидки, коины, доход, расход, прибыль, владелец, доли и партнёр. |
| Неизменяемая история | Готово | Изменения каталога и процентов не пересчитывают сохранённый заказ. |
| Отчёты и выплаты | Частично | Общая сводка показывает оборот, расходы, скидки, коины и прибыль. Партнёрские начисления фиксируются по пятницам, ожидающие выплаты отмечаются оплаченными и сохраняются в архиве. Нет произвольных периодов, разрезов, выплат владельцам и Excel-экспорта. |

## Инфраструктура

| Блок | Статус | Фактическое состояние |
|---|---|---|
| Docker/PostgreSQL/Alembic | Готово, требует production smoke test | Compose, healthcheck БД, persistent volume и цепочка миграций присутствуют. |
| Google Sheets | Готово | Товарные листы-категории, `Владельцы`, `Настройки`, русские служебные заголовки, нормализация, обратные исправления и встроенные изображения. |
| Deployment | Частично | Приложение готово к HTTPS deployment, но регламент webhook/polling, backup и мониторинг не документированы. |
| Автотесты | Не сделано | Есть ручные проверки и компиляция, но отдельного test suite в репозитории нет. |

Не выполненные блоки не следует считать готовыми до реализации пользовательского пути и production-проверки.
