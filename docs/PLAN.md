# План разработки

План составлен по `docs/specifications.xmind` и `docs/finances.xmind`. XMind читается как ZIP-архив, требования извлекаются из `content.json`. Прямые указания заказчика имеют приоритет: все пункты исходной карты про email удалены из реализации, web-админка заменена Telegram-admin flow, управление товарами перенесено в Excel. Фактическое покрытие требований зафиксировано в `docs/TZ_AUDIT.md`.
